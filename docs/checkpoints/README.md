## Cómo usar este paquete (2 minutos por checkpoint)

1. Abre el documento del checkpoint correspondiente y ten el repo en `main` abierto al lado.
2. La primera tabla de cada documento mapea **criterio → evidencia**; no improvises: lo que dice el criterio está respondido en la primera sección.
3. Si el checkpoint es una llamada en vivo: usa la sección "Guion de 90 segundos" y deja el resto para preguntas.
4. Si es un formulario o documento a subir: copia la sección "Para copiar/pegar" sin tocar nada más.
